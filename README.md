# Sisyphus

A task & project tracker, built from scratch as a one-day, hands-on run
through TypeScript on both ends, Supabase for data and auth, and Docker
for the whole stack.

## Stack

- **Frontend** — React + TypeScript (Vite)
- **Backend** — Express + TypeScript (REST API)
- **Database & Auth** — Supabase (Postgres, GoTrue), run locally via the
  Supabase CLI (its own Docker containers)
- **Containers** — Docker / OrbStack, orchestrated with `docker-compose`

## Structure

    frontend/     React + TS app
    backend/      Express + TS API
    supabase/     Supabase CLI config & migrations (generated by `supabase init`)
